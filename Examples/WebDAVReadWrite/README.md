# WebDAV 读写接入示例

`WebDAVExample.swift` 是可编译函数片段，展示递归建目录、非覆盖上传、服务端复制、移动/重命名、下载和删除。它不自动运行，也不含真实服务器或凭据。

## 接入

SwiftPM 引入 `BoneRemoteSyncCore` 与 `BoneRemoteSyncWebDAV`，将示例文件加入宿主 target。传入最终 collection URL、匿名或 Basic 凭据、普通本地文件、独立的新测试目录，以及尚不存在的本地下载目标。

示例会保留上传的原文件，仅删除它成功创建并重命名的副本。请使用专用验收目录，先确认外部写入授权。成功与异常路径都会等待 `disconnect()`；失败时不自动删除整个目录，避免误删既有数据或掩盖不确定的远端状态。

## 语义

- 上传、移动、复制的父目录必须已经存在；需要时先调用递归 `makeDirectory`。
- 非覆盖上传发送 `If-None-Match: *`；覆盖已有普通文件要求强 ETag 并发送 `If-Match`。不覆盖目录。
- MOVE/COPY 使用 `Overwrite: F`；目录复制递归执行。
- 上传会先生成私有磁盘快照，需要约等于文件大小的临时空间。无固定 SDK 文件大小上限，无断点上传。
- 写请求不自动重试。失败、取消、断开或超时可能已经改变远端，必须先核对状态，不能盲目重放或补偿删除。
- 207 不作为整项成功；锁管理、自定义属性写入、ACL 和 WebDAV 扩展协议不在本示例或当前 Core 接口范围内。

## 真实 NAS 验收清单（尚未执行）

1. 使用已授权的专用目录及最小权限账号连接 HTTPS 服务。
2. 递归建目录；重复创建确认幂等；文件同名确认冲突。
3. 上传空文件、中文/空格/`#?%` 文件名以及合适大小的二进制文件，下载后逐字节或 SHA-256 比对。
4. 验证非覆盖冲突和强 ETag 条件覆盖；确认已有文件与目录不被意外替换。
5. 文件及非空目录 COPY/MOVE 后核对内容；目标存在时确认不覆盖。
6. 在自建测试资源上验证 DELETE，确认根删除在客户端被拒绝。
7. 验证只读账号、服务端方法禁用、锁资源与网络中断；失败后重新检查远端实际状态。
8. 仅清理确认归本次验收所有的资源，不以错误返回推断资源未创建。

localhost fixture 只能证明受控协议场景，不能替代上述真实服务器验收。
